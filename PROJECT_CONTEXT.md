# AI Sales Assistant for Bitrix24

## Цель проекта

Создать frontend MVP приложения-помощника менеджера по продажам для Bitrix24.

Приложение должно помогать менеджеру во время звонка:
- видеть выбранный скрипт;
- отмечать заданные вопросы;
- видеть пропущенные обязательные вопросы;
- видеть следующий рекомендованный вопрос;
- открывать подсказки по возражениям;
- смотреть итог звонка.

## Sprint 1

Делаем только frontend-прототип.

## Технологии

- React
- Vite
- JavaScript
- CSS
- localStorage
- локальный JSON со скриптами

## Что запрещено в Sprint 1

- не подключать Bitrix24 API;
- не делать backend;
- не делать OAuth;
- не подключать LLM;
- не делать голосовую аналитику;
- не делать базу данных;
- не делать админку.

## Главная логика

Следующий вопрос = первый незаданный вопрос по порядку.

Прогресс = количество заданных вопросов / общее количество вопросов.

Обязательные незаданные вопросы показываются отдельным блоком.

Возражения открывают карточку с готовой рекомендацией.

Состояние сессии хранится в localStorage.   

## Боевая логика звонка

Приложение не управляет звонком.

Звонком управляет Bitrix24:
- начало звонка;
- соединение;
- завершение звонка;
- запись звонка;
- карточка лида / сделки.

В локальном прототипе кнопка “Симулировать завершение звонка” нужна только как dev-заглушка.

В боевой версии:
1. Bitrix24 сообщает, что звонок начался.
2. Приложение получает клиента и скрипт.
3. Приложение анализирует разговор и показывает подсказки.
4. Bitrix24 сообщает, что звонок завершён.
5. Приложение показывает итог звонка.
6. Приложение автоматически записывает результат анализа в таймлайн или поле CRM.

Менеджер не должен нажимать отдельную кнопку “Сохранить в CRM”.

## Текущий статус MVP

Сделано:
- React/Vite приложение запущено локально.
- Скрипт звонка хранится в `src/data/scripts.json`.
- Mock-контекст Bitrix24 хранится в `src/data/bitrixContext.json`.
- Состояние звонка сохраняется в localStorage по `callId`.
- Приложение определяет заданные вопросы по ключевым словам из расшифровки.
- Приложение определяет возражения по ключевым словам из расшифровки.
- Приложение показывает рекомендацию помощника:
  - если есть возражение — отработка возражения;
  - если возражений нет — следующий лучший вопрос.
- После завершения звонка формируется итоговый текст для CRM.
- Запись в Bitrix24 пока реализована как mock-функция `saveCallResultToBitrix`.

Важное:
- Кнопка “Симулировать завершение звонка” — временная dev-заглушка.
- В боевой версии завершение звонка должно приходить событием из Bitrix24.
- Менеджер не должен нажимать отдельную кнопку “Сохранить в CRM”.
- Результат должен записываться автоматически после завершения звонка.

## Рабочая точка MVP

Проверено:
- приложение работает в mock-режиме;
- режим отображается на экране как `mock`;
- расшифровка определяет вопросы по ключевым словам;
- возражение “дорого” определяется автоматически;
- рекомендация помощника меняется на отработку возражения;
- итог звонка формируется;
- mock-запись в Bitrix24 проходит;
- на итоговом экране отображается Activity ID.

Текущий App.jsx считается рабочей версией.
До начала реальной интеграции с Bitrix24 не менять App.jsx без необходимости.
